# Retired hyprdynamicmonitors profiles

hyprdynamicmonitors was replaced by hyprmoncfg in commit 503eaa6, which removed the
tool and its six tracked profiles. Those six remain recoverable from git history at
503eaa6^.

These two never were: they sat untracked in the working tree and would have been lost
with the migration. They are kept here — deliberately outside any stow package, so
nothing symlinks them into ~/.config — because they document real physical layouts
that hyprmoncfg has no profile for yet.

Recovered from the Phase A backup taken at 2026-09-26 11:12, seventeen minutes before
the migration deleted them.
